# Roadmap

## Weather check before each lesson

Status: not built.

> have the app do a weather run for each lesson 1 hour before start time. It will check multiple local radars, future radars and lightning apps, then come up with a percentage chance that the lesson would be impacted by weather. If it comes up with a better than 60% chance it will be affected, the class will be canceled. The parent will get a notification and so will the instructor. Parents will be pushed to reschedule in the app. If they do not reschedule within 24 hours, it automatically gets moved to the end of their package.
